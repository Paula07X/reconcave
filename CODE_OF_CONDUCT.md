# Code of Conduct

## Our commitment

This project welcomes contributions and participation from anyone,
regardless of experience level, background, or identity. Maintainers and
contributors are expected to treat each other with basic professional
courtesy in issues, pull requests, discussions, and any other project
space.

## Expected behavior

- Be respectful of differing viewpoints and levels of experience.
- Give and accept constructive feedback gracefully — critique the code
  and the idea, not the person.
- Focus disagreements on what's technically best for the project.
- Assume good faith. Most friction in open-source discussion comes from
  misread tone, not actual hostility.

## Unacceptable behavior

- Personal attacks, insults, or derogatory comments, whether about a
  person's code, background, identity, or anything else.
- Harassment of any kind, public or private.
- Publishing others' private information without consent.
- Sustained disruption of discussions, issues, or reviews.
- Any conduct that would reasonably make another contributor feel unsafe
  or unwelcome participating in the project.

## Reporting

If you experience or witness behavior that violates this code of
conduct, please report it privately to the maintainer (see contact
details in `pyproject.toml`). Reports will be handled with discretion.
Maintainers commit to reviewing every report and taking action
proportionate to what happened — from a private conversation up to
removal from the project's spaces for repeated or severe violations.

## Scope

This applies within all project spaces (issues, pull requests,
discussions, code review) and in any other context where someone is
representing the project publicly.

## Attribution

This is an original document written for this project, informed by the
general norms common to most open-source codes of conduct rather than
